# appunti-ict-unito
Appunti liberi e gratuiti dei corsi della triennale ICT (Innovazione sociale, comunicazione, nuove tecnologie) dell'Università degli Studi di Torino, scritti da Francesco Screti. Possono contenere errori e non intendono sostituire le lezioni frontali, anche se ho cercato di renderli quanto più possibile corretti, completi e comprensibili.
