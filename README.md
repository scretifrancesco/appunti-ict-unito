Appunti liberi e gratuiti dei corsi della laurea triennale in Innovazione Sociale, Comunicazione e Nuove Tecnologie (ICT) dell'Università degli Studi di Torino, scritti da Francesco Screti (me stesso) in LaTeX e disponibili in PDF.

## Disclaimer

Gli appunti non intendono sostituire in alcun modo le lezioni frontali, anche se ho cercato di renderli quanto più possibile corretti, completi e comprensibili. 

## Corsi

Ogni corso ha la propria cartella, con il PDF degli appunti.

| Sigla | Nome completo |
|---|---|
| [AD](AD) | Analisi dei Dati |
| [DCED](DCED) | Diritto Commerciale dell'Era Digitale |
| [DPMD](DPMD) | Diritto Privato dei Mercati Digitali |
| [EED](EED) | Economia dell'Età Digitale |
| [EGIMB](EGIMB) | Economia e Gestione delle Imprese e dei Modelli di Business |
| [EBDDM](EBDDM) | Elementi di Basi di Dati e Data Mining |
| [INFGIU](INFGIU) | Informatica Giuridica |
| [IxD](IxD) | Interaction Design |
| [MKT](MKT) | Marketing |
| [POLFILTEC](POLFILTEC) | Politica, Filosofia, Tecnologia |
| [SNM](SNM) | Sociologia dei New Media |
